# 8 | Eight — menup

منوی QR کافه **8 | Eight** روی Next.js: منوی مشتری، پنل مدیر و گارسون، پیش‌فاکتور، دخل‌وخرج و میزها.

## راه‌اندازی

```bash
cp .env.example .env
npm install
npm run dev
```

`DATABASE_URL` پیش‌فرض فایل SQLite در `data/dev.db` است. اسکیما در اولین استفاده ساخته می‌شود.

| متغیر                                 | نقش                                         |
| ------------------------------------- | ------------------------------------------- |
| `DATABASE_URL`                        | اتصال دیتابیس (لوکال: `file:./data/dev.db`) |
| `MANAGER_PASSWORD` / `ADMIN_PASSWORD` | ورود مدیر (پیش‌فرض `eight`)                 |
| `WAITER_PASSWORD`                     | ورود گارسون (پیش‌فرض `waiter`)              |

ورود: `/admin/login` — مدیر به داشبورد می‌رود، گارسون به پیش‌فاکتورهای امروز.

## چه چیزی آماده است

**منوی مشتری** (`/`) — اسپلش، دسته‌ها، کارت آیتم، جزئیات، ناموجودی، QR بدون انقضا.

**پنل مدیر** (`/admin`)

- داشبورد: خلاصه هفته، نمودار دخل/خرج، میانبرها، میزهای خالی، ناموجودی
- پیش‌فاکتورها (هفته، شنبه تا جمعه به وقت تهران)
- میزها: اشغال با یک کلیک، مدت نشستن؛ سفارش روی میز همان میز را اشغال می‌کند
- دخل و خرج: جمع سفارش‌ها + هزینه دستی
- دسته‌ها و آیتم‌ها (قیمت، تصویر، موجودی، قهوه/سود/آفر)
- تنظیمات و QR منو / ورود گارسون / ورود مدیر / لوکیشن

**گارسون** — ساخت سفارش از منو، پیش‌فاکتور امروز، میزها. بیرون‌بر = میز `۰`.
